# Paper

The journal manuscript "The book Ramsey number R(B_57, B_58) = 231" (one column, Elsevier
`elsarticle`), the version submitted to Discrete Mathematics and deposited on Hexagon.

- `paper1/book-ramsey-58.pdf` — the PDF.
- `paper2/book-ramsey-58-tex.zip` — its LaTeX source with the figures; `pdflatex main.tex` three
  times compiles it.

The code, data and Lean proofs it cites are release v2.1.0,
https://github.com/creelie/Breakthrough-problems-2/releases/tag/v2.1.0.
